# Médias facultatifs

Ce dossier peut contenir des portraits, logos et tracés utilisés pendant le développement local. Ces fichiers sont exclus du dépôt public par `.gitignore` tant que leurs droits de redistribution ne sont pas établis. La licence MIT du code ne les couvre pas.

L'application doit fonctionner sans ces médias : elle utilise des repères textuels ou indique qu'un tracé est indisponible. Pour ajouter des médias à une distribution, documentez au préalable la source, l'auteur, la licence et les attributions dans [`THIRD_PARTY_ASSETS.md`](../../THIRD_PARTY_ASSETS.md).
